# Abitare il colore — Terra / Soglia / Luce

Progetto nativo Spazio, interamente modificabile. Versione separata dalla prima mostra.

Tre immagini create con lo strumento integrato image_gen; nessuna API a pagamento configurata. Originali: terra.png, soglia.png, luce.png in questa cartella; copie WebP incorporate nel file progetto. Le immagini rappresentano opere immaginarie, non opere di artisti reali.

## Prompt utilizzati

1. Create an original museum-quality abstract painting, landscape ratio 3:2, edge-to-edge artwork only no frame no room no typography. Title concept 'Sedimenti': deep burnt sienna, oxblood, muted terracotta, chalk ivory. Weathered mineral pigments on coarse linen, bold asymmetrical large vertical blocks intersected by fine etched lines, layered translucent earth washes and scraped plaster textures. Restrained contemporary fine art, sophisticated composition with breathing space, tactile complex detail, not generic digital shapes. Flat orthographic reproduction even lighting.

2. Create an original museum-quality abstract painting, landscape ratio 3:2, edge-to-edge artwork only no frame no room no text. Title concept 'Soglia': midnight petrol blue, smoky teal, charcoal, subtle oxidized copper, pale ivory. A mysterious luminous narrow vertical opening slightly off-center in a field of layered deep mineral blue, horizontal ghost marks and delicate distressed edges. Hand painted encaustic and plaster tactile surface. Quiet, profound, highly sophisticated fine art composition. Flat orthographic art reproduction with even lighting.

3. Create an original museum-quality abstract painting, landscape ratio 3:2, edge-to-edge artwork only no frame no room no text. Title concept 'Luce sospesa': warm ivory, pale gold ochre, fog gray, restrained charcoal. A large atmospheric luminous disc partially dissolved into fine layers of translucent pigment, delicate charcoal arcs below, abundant negative space, subtle impasto and aged gesso texture. Poetic atmospheric contemporary painting, sophisticated and tactile not vector graphics. Flat orthographic art reproduction even lighting.
